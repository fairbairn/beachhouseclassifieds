## Field Legend

- Files: total detail JSONs found for adapter
- Core: files with all required core fields (external_listing_id, detail_url, fetched_at, html_path)
- Profile: files with property_profile
- Availability: files with normalized_availability.days
- Description+: files with non-empty description_expanded
- Amenities+: files with non-empty amenities
- Location+: files with non-empty location object
- Media+: files with media_gallery.image_urls containing at least one URL
- Rates: files with non-empty normalized_rates.days (non-blocking, forward-compat signal)
- Image URLs: aggregate count of media_gallery.image_urls[] across all files for the adapter
- Avg Img/List: Image URLs / Files (values <= 1 indicate under-optimized media extraction)
- API Avail: adapter has a direct provider endpoint for day-level availability updates (code-level signal)
- API Rates: adapter has a direct provider endpoint for dynamic nightly rates updates (code-level signal)
- API Quote: adapter has a direct provider endpoint for ad-hoc pre-reservation pricing (code-level signal)
- Quote Runtime: adapter has a runtime executor implemented under `src/lib/pricing/quote-runtime/adapters/<adapter>.ts` and wired for migration readiness tracking
- Pricing Records: count of per-listing pricing JSON records under `details/pricing` (excluding `index.json`)
- Ready: combined conformance status for the adapter (all required quality thresholds pass, `Pricing Records == Files`, `API Quote = ✅`, and `Quote Runtime = ✅`)
- Notes: explicit required failure causes for non-ready adapters; none for ready adapters

This matrix does not certify adapter-level quote/estimation/handoff conformity.

## Ready Rule

An adapter is Ready only when all required gates pass:

- Description threshold: `description_expanded` length >= 600 characters for 100% of files.
- Amenities threshold: `amenities.all.length >= 2` for 100% of files.
- Media threshold: `media_gallery.image_urls.length >= 5` for 100% of files.
- Availability threshold: `normalized_availability` span >= 365 days for 100% of files.
- Pricing parity threshold: `Pricing Records == Files`.
- Quote API threshold: `API Quote = ✅`.
- Quote Runtime threshold: `Quote Runtime = ✅`.

Preferred (non-blocking):

- Availability preferred horizon: span >= 730 days.
